# async-coder for VS Code

An authenticated local agent sidebar, editor actions, tool permissions, session status and native diffs. Install `@async-coder/cli`, open a trusted local workspace and select the async-coder activity-bar icon.

See [the integration guide](../../docs/vscode.md) for configuration and shortcuts. To develop, open this directory, run `bun install` and press F5. Run `bun typecheck`, `bun test` and `bun run package` here before distributing the extension.
