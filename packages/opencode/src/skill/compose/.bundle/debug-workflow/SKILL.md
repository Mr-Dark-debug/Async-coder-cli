---
name: debug
description: Reproduce failures, trace their cause, and verify a targeted fix.
---

Use the bundled `compose:debug` systematic debugging workflow for detailed investigation.
Gather the actual error, environment, and reproduction steps. Read the failing implementation and its callers.
Form a specific hypothesis and test it with observable evidence. Fix the underlying cause with a focused change.
Add a meaningful regression test where practical, then run relevant checks and the original reproduction.
Report verified outcomes and unresolved limitations. Never substitute a plausible explanation for reproduction evidence.
