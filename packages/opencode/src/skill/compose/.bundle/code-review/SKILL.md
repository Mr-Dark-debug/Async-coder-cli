---
name: code-review
description: Review changes for actionable correctness, security, and regression defects.
---

Read repository instructions and inspect the actual diff, surrounding implementation, and callers.
Trace concrete inputs to failure conditions. Prioritize findings by impact and identify file and line references.
Check tests and compatibility boundaries. Distinguish confirmed defects from uncertain concerns.
Report actionable findings first and state the review's verification limits. Do not modify files unless requested.
