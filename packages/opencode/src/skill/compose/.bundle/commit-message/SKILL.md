---
name: commit-message
description: Write a concise commit message from the actual staged changes.
---

Read the repository contribution guidelines and inspect `git diff --cached` and `git status`.
Describe the concrete resulting behavior and its purpose. Follow the repository's commit style.
Do not include unverified test claims or stage unrelated changes. If no changes are staged, explain that limitation.
Only commit when the user's request authorizes it.
