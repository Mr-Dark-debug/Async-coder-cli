Read the requested code, its callers, and relevant types or tests.
Explain the purpose first, then follow data and control flow using a concrete example.
Include important side effects, error paths, and dependencies. Cite files and avoid unsupported assumptions.
Adapt technical depth to the user's request. Keep the explanation focused and do not edit code unless asked.
