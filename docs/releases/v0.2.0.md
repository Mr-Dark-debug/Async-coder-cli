# async-coder 0.2.0 — Code intelligence, background jobs and recovery

This upgrade extends native MCP, LSP, agent, session and desktop architecture with installed-server discovery, compatible MCP configuration, lifecycle hooks, scoped worktree management, explicit checkpoints and structural repository maps.

Desktop session tabs and tray behavior retain lavender styling. The TUI adds search and checkpoint controls. VS Code adds an authenticated local sidebar, editor actions, permissions and native diffs. Offline exports work without a hosted sharing service.

Validated model catalogs and Zen recommendations distinguish free prices from unknown prices. Provider queues honor streams/cooldowns; explicit fallback avoids replaying partial responses/tools. Windows path isolation and memory indexing receive regression fixes.

The integrated release also adds background jobs, team worktrees, verification receipts, spend caps, context inspection, memory recall, side notes, sandbox configuration, device pairing, chat bridges, marketplace commands and local evaluation. Routines run while the server process is running. Job cancellation stops verification, and spend caps are checked before repair calls.

Project-provided skills now require explicit project trust. Set `skills.trust_project` or use `async-coder trust grant` after reviewing the repository. Confined shell sandbox modes require a supported Linux/macOS backend; Windows refuses confined commands.

See [README](../../README.md) for guides and the [validation report](./v0.2.0-validation.md) for measured results. Independent hosted Zen/sharing services are not provisioned. Native Linux/macOS execution, native desktop/VS Code host interaction, authenticated bridges and whisper.cpp have not been verified live.

```sh
npm install -g @async-coder/cli@0.2.0
async-coder --version
```

Publication follows AGENTS.md: registry binary, registry CLI, clean install, then GitHub. Actual results are recorded in the validation report.
