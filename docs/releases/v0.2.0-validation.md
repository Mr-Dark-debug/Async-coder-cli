# 0.2.0 validation

Validation is performed on Windows x64 with Bun 1.3.11. Source changes extend the existing native services rather than creating parallel implementations. The October 6 release verification includes the integrated jobs, budgets, sandbox, recall and bridge work merged in PR #3. Earlier checks below describe the foundation upgrade; the integrated build and final core result remain separate gates.

## Verified

- Twelve platform binaries cross-compiled using SHA256-verified official Bun runtimes. Windows x64 and baseline executables report `async-coder 0.2.0`. Linux/macOS binaries require execution checks on their respective hosts.
- All twelve workspace package typechecks pass. The pre-push hook now invokes each package's `bun typecheck` from its package directory.
- October 6 integrated app unit suite: 320 passing tests. Shared: 53 passing tests. UI: 14 passing tests. VS Code: three tests, lint, typecheck and production bundle pass.
- Desktop production main/preload/renderer build and thirteen desktop tests pass.
- Real browser session tabs: two backend-created sessions, switching, close-active, close-last, reload persistence and backend-session preservation pass. Both browser regressions pass together after the final source changes.
- Live nested-project Git review displays highlighted split before/after content. Eighteen Git/VCS tests include nested project path/hunk regression coverage. Opening a review file immediately selects its source tab and displays its contents; a real nested-project browser regression verifies the first opening.
- MCP stdio, HTTP and SSE tests perform actual initialize, discovery, invocation, disconnect and reconnect. The SDK stdio fixture is bundled before connecting to exclude cold module loading from the protocol deadline. Repeated concurrent transport checks pass; transport/request deadlines remain three seconds.
- LSP protocol tests exercise diagnostics, completion and rename proposals through an actual JSON-RPC fixture. Rename proposals remain unapplied.
- Hook, skill, instruction and configuration acceptance checks pass. Local instructions preserve existing ignore rules; project skills override bundled defaults.
- Scoped worktrees, checkpoints, offline sharing, repository maps, provider fallback and pricing have focused regression coverage. The whitelist rejection test reads the actual actor thread and verifies the persisted rejected tool result.
- Session/runner verification: 58 passing tests and ten existing platform skips. Reliability: 23 passing tests. Workflow/worktree: 34 passing tests. Installer postinstall: six passing tests, including a real wrapper-to-executable launch.
- All thirteen release tarballs contain their executable entries and have SHA256 checksums. A clean local npm installation of the CLI/runtime tarballs reports `async-coder 0.2.0` and exposes the new commands. Registry installation remains a separate gate.

## Outstanding release gates

- Complete the integrated core suite and resolve every failure. The foundation upgrade's latest isolated run passed 3,414 tests with one MCP fixture startup failure; that fixture has been fixed and its concurrent transport checks now pass.
- Rebuild the integrated source for all twelve targets and verify native Windows execution. The earlier foundation build passed for all targets; native execution on other platform hosts remains unverified.
- Publish and verify npm runtimes before the installer; smoke-test the registry installation before publishing GitHub's draft.

The model audit snapshot was checked October 1, 2026. Provider credentials and availability remain separate from catalog discovery. Independent async-coder Zen/sharing services have not been provisioned; existing provider endpoints and offline exports are documented accurately.

The isolated Windows worktree uses `bun install --frozen-lockfile --ignore-scripts` followed by the repository's PTY setup. The default install hit a long-path native build failure in `tree-sitter-powershell`; this project imports its packaged WASM grammar. Desktop and VS Code native host interaction, Linux/macOS sandbox backends, authenticated chat bridges and whisper.cpp remain separate from unit/build verification.
